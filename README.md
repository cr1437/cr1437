# 以下是我的项目
## [Shizako](https://github.com/cr1437/Shizako)
他是一款基于kotlin开发的，用于安卓adb玩机，当然，你root了也可以使用，它的功能很强大，你所想到的功能它基本都有，还有很多进阶玩法，例如我们集合了dhizuku，以及我们还有很多个性化设置，Tasker支持，adb兼容桥，还支持一键激活软件，我做这个的初衷是希望玩机时不用下这么多软件，占用后台，集中一个就好，后续我还会推出插件功能，如果你感兴趣，或者觉得好用，请给我的项目给个star，谢谢！

第二款是我的Astrbot插件
## [Astrbot管理GitHub](https://github.com/cr1437/astrbot_plugin_github)
